## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

- A web browser such as Google Chrome, Microsoft Edge, or Firefox.
- A code editor such as Visual Studio Code.
- Git, if you want to clone the repository using Git.

### Installation

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project folder**

```bash
cd tutorial-fb-clone-website
```

**3. Open the project**

Open the project folder in Visual Studio Code.

**4. Run the website**

Open the `index.html` file in your browser, or use the Live Server extension in VS Code if appropriate for your project.
